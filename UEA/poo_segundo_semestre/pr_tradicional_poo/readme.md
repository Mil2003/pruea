# Comparación entre Programación Tradicional y POO en Python

Este proyecto tiene como objetivo comparar dos paradigmas de programación en Python, la **Programación Tradicional** y la **Programación Orientada a Objetos (POO)**, mediante la implementación de un programa que calcula el promedio semanal de temperaturas.

## Contenido del Repositorio

- `programacion_tradicional.py`: Implementación del programa usando Programación Tradicional.
- `programacion_poo.py`: Implementación del programa usando Programación Orientada a Objetos (POO).
- Este archivo `README.md` con una descripción y comparativa de ambos paradigmas.

---

## Programación Tradicional

### Características:
- Se basa en funciones independientes para manejar la lógica del programa.
- Usa estructuras de datos simples como listas para almacenar información.
- Es ideal para programas pequeños o con requisitos específicos.

### Ventajas:
1. Sencillo de implementar y entender.
2. Menor curva de aprendizaje, ideal para principiantes.
3. Requiere menos líneas de código para programas simples.

### Desventajas:
1. Difícil de escalar en proyectos grandes.
2. Menor organización del código.
3. Requiere más esfuerzo para mantener y extender el programa.

---

## Programación Orientada a Objetos (POO)

### Características:
- Se estructura en torno a clases y objetos.
- Permite encapsular datos y métodos dentro de una clase.
- Facilita el uso de conceptos como herencia y polimorfismo.

### Ventajas:
1. Código más organizado y modular.
2. Escalable y reutilizable en proyectos más grandes.
3. Facilita la colaboración en equipos debido a la clara separación de responsabilidades.

### Desventajas:
1. Requiere más tiempo para diseñar e implementar.
2. Mayor complejidad para principiantes.
3. Puede ser excesivo para programas simples.


## Ejecución de los Programas

### Programación Tradicional:
```bash
python programacion_tradicional.py
```

### Programación Orientada a Objetos (POO):
```bash
python programacion_poo.py
```


## Conclusión

Ambos paradigmas tienen sus puntos fuertes dependiendo del contexto:
- **Programación Tradicional** es útil para scripts pequeños y rápidos.
- **POO** es una excelente elección para proyectos grandes, escalables y mantenibles.
