# Técnicas de Programación: Ejemplos de POO en Python

## 📚 Descripción del Proyecto
Este repositorio contiene ejemplos prácticos de las principales técnicas de Programación Orientada a Objetos (POO) en Python, desarrollados como parte de un ejercicio académico.

## 🎯 Objetivos
- Demostrar la aplicación de conceptos fundamentales de POO
- Ilustrar cada técnica de programación con ejemplos claros y concisos

## 🧩 Técnicas Implementadas

### 1. Abstracción
- **Ubicación**: `/abstraccion`
- **Concepto**: Define interfaces y métodos abstractos para crear una estructura base
- **Ejemplo**: Jerarquía de formas geométricas con métodos abstractos de cálculo de área y perímetro

### 2. Encapsulación
- **Ubicación**: `/encapsulacion`
- **Concepto**: Oculta los detalles internos de una clase y controla el acceso a sus atributos
- **Ejemplo**: Implementación de una cuenta bancaria con métodos controlados de depósito y retiro

### 3. Herencia
- **Ubicación**: `/herencia`
- **Concepto**: Permite crear nuevas clases basadas en clases existentes, reutilizando código
- **Ejemplo**: Jerarquía de empleados con clases base y derivadas

### 4. Polimorfismo
- **Ubicación**: `/polimorfismo`
- **Concepto**: Permite que objetos de diferentes clases respondan de manera única a un mismo método
- **Ejemplo**: Diferentes tipos de animales que implementan un método de hacer sonido

## 🚀 Cómo Ejecutar los Ejemplos

1. Asegúrate de tener Python 3.x instalado
2. Clona el repositorio
3. Navega a la carpeta del ejemplo que quieras ejecutar
4. Ejecuta el script con Python, por ejemplo:
   ```bash
   python abstraccion/formas.py
   ```
